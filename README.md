# api_simpsons

INTERGRANTES: Walter Ivan Rodriguez Ancheta
              Edwin Ernesto Marquez Amaya
              Jasmin Alejandra Reyes Silva

DESCRIPCION: Esta aplicación permite a los usuarios explorar la información detallada de la serie animada los Simpson a través del consumo de una API REST. Los usuarios pueden consultar datos sobre los distintos personajes, explorar sus detalles y guardar sus preferidos en una lista personalizada de favoritos.

FUNCIONALIDADES: 1. Catalogo de personaje
                 2. Detalle y navegacion 
                 3. Busqueda por nombre
                 4. Paginacion 
                 6. Favorios persistente 
                 7. Estados de la Interfaz
